# Research authority and milestone documents

This directory groups the milestone specifications and protocols that were
previously stored in the repository root. The documents retain their original
contents; their paths changed only to make the repository easier to navigate.
The current research status and reproduction entry points remain in the
repository README and the top-level `docs/` guides.

## Milestone 4R

[`milestone-4r/`](milestone-4r/) contains the 4R formal specifications,
experiment protocols, theory audits, implementation plan, and implementation
prompts. The completed 4R-A report and later scoped reports remain directly in
`docs/`.

## Milestone 5

[`milestone-5/`](milestone-5/) contains the original multistop theory and audit,
the B21 exact-validation protocol, and the cut checkpoint. Current M5 reports,
v2 contracts, and M5-D status remain in `docs/` and are linked from the root
README.

These files document different stages and scopes. A historical or bounded
protocol is not by itself evidence that a later milestone or a full real-data
reproduction has passed.
