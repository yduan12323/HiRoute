## Exactness and partial coverage

Strictly positive travel times give a finite shortest simple path and an
acyclic tight-edge graph. Dijkstra's exact labels and reverse settlement order
compute target-reaching masks over all tight successors. For a requested
target, the lexicographically smallest eligible next literal node yields the
smallest complete node tuple; among identical node paths, the smallest full
literal edge-ID at the first differing parallel edge gives the edge-tuple tie.
Actual length is the sum on that selected path, never a separately minimized
length. Predecessors only witness attainment; they need not be canonical.
Positive cycles, unreachable nodes, parallel edges, aliases and the terminal
remain in the complete graph/domain. Arbitrary-precision rational arithmetic
and bounded temporary-storage admission preserve exactness; resource failure
does not imply a mathematical result.

`SourceUnit` retains complete original `.sources`, `.targets`, Site order,
anchors and effects. Its JSONL schema explicitly names the one source, and
requires all its target pairs, including exact zero aliases and explicit
unreachability. `SourceSession` returns a source-only mapping with the original
denominators and unrun count. It cannot issue `Checked`, and ordinary `Session`
and its `finish` reject source units. The real worker additionally compares the
entire unit header to the immutable frozen domain; a shrunk or changed literal
domain cannot masquerade as this experiment. Cached source completion rechecks
the actual retained disk inputs.
