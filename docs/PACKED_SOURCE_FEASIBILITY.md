## One coherent prototype

The candidate graph is an immutable binary CSR: literal node/edge IDs are in
sorted UTF8 arenas, offsets and arc references are packed, and each exact
positive rational has variable-length unsigned integer magnitudes. No global
denominator LCM or floating routing is used. A bounded16MiB pread page cache
avoids a resident graph/string dictionary. The current constructor is expressly
synthetic-only (8192nodes/32768edges); a bounded external-join real constructor
and its complete raw-to-packed identity validation do not exist here.

The source loop has direct Fraction labels, packed predecessor/settlement
arrays, a dense exact bitmask and an indexed binary heap. One heap entry per
vertex bounds frontier storage, including decrease-key; stale duplicates cannot
silently accumulate to an edge-sized heap. The unit regressions prohibit any
SQLite connection during this exporter. Packing and independent checking still
use SQL and their costs are included, not described as zero SQL.

All weight/label operations remain arbitrary-precision Fraction arithmetic.
The explicit512MiB label-object quota and16MiB arithmetic temporary admission
stop with UNKNOWN/resource outcome, never precision clipping. Uint32 is used
only for identities/indices: the previously verified2986695nodes/5900232edges
are below its reserved sentinel. Uint64 offsets are sufficient under the
explicit4GiB file envelope. These facts do not bound path arithmetic to64bits.

Exact Dijkstra settles every reachable node. Strictly positive tight edges
form a DAG, so reverse settlement order gives exact target-reach masks. Greedy
eligible successors in full literal-node then literal-edge-ID rank produce the
same full node/edge tuple tie as the original contract. Actual selected length
is summed on that path. Export walks a path twice (length then steps), avoiding
a resident all-path list. No candidate/domain/history/depth reduction is made.

## Independent proof and lossless transport

The new graph, source generator and binary certificate are all UNTRUSTED.
The original independently validated raw graph and SourceSession/Session are
unchanged. They check every node and raw edge: Bellman inequalities, attaining
predecessors, directed unreachable cut, tight-DAG masks, canonical selected
paths and actual length. A wrong candidate weight can pass a schema/hash but
is rejected by this mathematical boundary.

A compact source certificate stores node-order reach flags, variable-length
label magnitudes, literal edge-ID ranks and all target-mask bits. It binds the
actual pack, graph, source, full target order and unit-path bytes. Its decoder
emits the original JSONL language. The exporter hashes an independently rendered
reference transcript without storing a duplicate file, and requires byte-exact
SHA/length equality after decoding. The unchanged checker consumes the decoded
JSONL. Bad mappings/labels/flags/masks/lengths/domains/suffixes fail closed.
Codec success is not a road certificate.

## Resource estimates and limits

For the frozen real graph's established all-raw-endpoints node domain, unique
node text plus unique edge-ID text consumes no more bytes than the disjoint raw
identity fields. Positive reduced binary magnitudes use no more than original
numeric text bytes plus one denominator byte per integer weight; each weight
has an8byte length header. Thus packed arena<=raw_bytes+18E. Fixed sections are
64+16(N+1)+8(E+1)+24E. This gives a conservative packed-file upper bound,
not a measured real file or RSS. Explicit isolated nodes would need their
separate input-byte term; the frozen real graph has the established union domain.

Generator admission separately accounts label references, predecessor/order/
heap/position arrays, settled bytes and ceil(65/8)mask bytes per node, plus
512MiB labels,16MiB pages,16MiB arithmetic,16MiB serialization,128MiB
interpreter/allocator reserve and4MiB container/cache overhead. The reserve is
an admission model, not a universal Python RSS theorem; the1GiB external guard
remains necessary. Real label growth and completed-source RSS are unmeasured.
Generator labels must not remain live in the independent checker worker.

The resource report also gives conditional binary-certificate and decoded-JSON
upper bounds using measured current Fraction/int object layouts. Integer binary
payload<=getsizeof(integer)-int_header. With label quota L, positive-root count
R>=1, fixed per-reachable record overhead21bytes (65target bits), each binary
source is bounded by its header+N+L-(Fraction_header+2int_header-21)R.
Decimal digits<=ceil(bits/3)+1 because2^3<10. Raw node plus attaining-predecessor
IDs use disjoint original identity fields; valid UTF8 JSON escaping is at most2x.
These yield a conditional decoded-JSON bound, not an actual certificate size.

A possible future storage policy would retain the lossless binaries and input
pack, use one decoded JSON at a time, reserve two1GiB active SQL files and a
2GiB cumulative selected-path quota, and preserve2GiB free disk. It would need
verified cleanup of regenerable temporary indexes/state and stop at the first
incomplete source. Such a driver/file-size enforcement/real external pack
construction is not implemented or admitted. Historical free disk is not a new
live preflight. Failure at any quota yields incomplete/uncertified, not infeasible.
