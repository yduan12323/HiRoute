# Deterministic suffix blocks and the first resource run

The frozen C01 population remains 695,712 unique original-family/word/arrival-band
models and 7,652,832 original model occurrences. The descriptor plan assigns
stable global ordinals and partitions them into 2,718 blocks of at most 256
models. The last block contains exactly 160 models. Block size changes storage
and scheduling, not the language or any mathematical constraint.

`AdmittedSuffixPopulation` authenticates the existing completed structural
replay and logical-count returns/manifests, then binds every indexed family to
a genuine fresh `CheckedBundle`. It does not manufacture a `CheckedTrace`.
Original query, family and action ordering, ancestry commitments and repeated
logical ranges remain explicit in the query projections.

The first resource run chooses the first distinct canonical block intersecting
each prefix depth 0–3. Its four exact block IDs and 1,024 full model identities
are written before matrix construction or candidate optimization. This uses the
already frozen descriptor order, not suffix LP outcomes. The results are
ordinary full-population work that can be retained for later continuation;
the subset is not a representative statistical sample or a query-wide proof.

## Execution and evidence

Four persistent workers retain imports across models. Their generation, source,
block and model identities are bound in every response. Each worker has one
outstanding model, 1 GiB address space, a 768 MiB exec-lifetime memory check,
a 30-second external model deadline and at most 12 native LP passes per model.
The existing five-stage strict feasibility/attainment protocol is unchanged.
Numerical certificate caching is disabled for this resource baseline.

The coordinator independently checks every regime using the existing checker.
It streams the complete model, ordered tasks and certificates into a canonical
JSONL/gzip archive. Only small results and one representative winning record per
block stay resident. Compact block and segment summaries retain all primary,
secondary and winning tie indices and every exclusion count. A reported
nonempty block optimum or approach also needs a checked physical witness.
Unresolved and unsubmitted models prevent complete block aggregation.

Each complete certificate-block boundary is sync-flushed. This preserves
recoverable JSONL prefixes after a process interruption. Such checkpoints are
explicitly provisional: reuse requires fresh exact certificate replay against
the same declared identities and source bindings. A checkpoint flag or an
interrupted gzip prefix alone grants no acceptance. This pilot command does not
automatically skip prior work or trust old completion flags.

The new run has its own explicit 900-second absolute deadline and 512 MiB
conservative evidence subquota. The existing writer's metadata headroom,
per-file charges and doubled byte reservations count toward that subquota.
Uncompressed archive bytes are separately limited to 512 MiB, with 8 MiB per
JSONL row. The existing 20 GiB group RSS cap, 16 GiB host reserve and 20 GiB disk
floor remain. This is separate from the earlier 480-second eight-model run.

Exact checking and physical lifting have their own 30-second limits. Evidence
publication is bounded by the absolute run deadline and byte quotas. A deadline
after a checker has returned a receipt cannot turn that receipt into accepted
evidence: the outer attempt fails. Complete acceptance additionally requires
clean transport shutdown/reaping and final source, capture and population
rechecks. Query-optimum, full-population and literal-G8 flags remain false.

## Launch boundary

The entry point is
`experiments.time_cut_v2.recorded_real.block_pilot`. Its explicit source,
historical-plan, completed-replay, logical-count, capture and CPU arguments match
the earlier preview runner. It does not rerun the route solver. Source review,
Python 3.11 preflight and a separately admitted fresh attempt are required.

Focused preflight modules are `test_suffix_aggregate_stream`,
`test_suffix_block_plan`, `test_indexed_suffix_population`, `test_lp_stream_jobs`,
`test_suffix_block_certificates`, and `test_suffix_block_archive`, in normal and
`-OO` modes. Cloud tests use fake candidates and hand certificates only.

Use measured per-depth construction, solving, exact-checking and storage costs
to set later full-run windows. No full-run duration or evidence estimate follows
from the eight-model calibration alone. Original-query lower-bound closure
requires complete certified segment languages, their exact projection back to
every original occurrence, and the query-specific bound audit. Winner witnesses
do not replace that coverage proof.
