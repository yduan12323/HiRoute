# HiRoute positioning — bounded evaluation report

HiRoute studies single-trip EV stop planning with continuous positive charging and optional scheduled activity, allowing same-stop charge/service overlap. Its research contribution concerns explicit attained-face semantics, constructive witnesses, safe indexed bounds and auditable exact-search scope.

The current evidence does not show a production-scale speed advantage. Original main exact completion is 0/192; small fixtures and a real feasible recovery witness support narrower claims. The fixed supplement is terminal with 23 pre-search timeouts and one infrastructure-unknown interruption. The separate real trial reconstructed depth 1 in both methods with independently replayed feasible witnesses; both exact searches remained censored. The task permits a scale-limited or no-demonstrated-benefit conclusion, with remaining implementation and accounting gates stated explicitly.

Use paper/related_work.md for the existing three-family comparison. No verified common-input external baseline run or published-method superiority is claimed. Transportation comparisons require matched, independently replayed witnesses and explicit heuristic/exact status. A future holdout requires algorithm, inputs, candidate policy and statistical freeze first; no holdout is executed for this report.
